# Vetary — AI-powered pet health app

Live app: https://vetary.app | iOS: https://apps.apple.com/app/id6803421084 | Android: https://play.google.com/store/apps/details?id=com.vetary.app

## The problem

Pet owners managing chronic conditions (epilepsy, diabetes, thyroid issues) struggle to track medication adherence, symptoms, and history accurately, and arrive at vet visits unable to answer "when did this start?" or "did I give yesterday's dose?"

## What I built

A full-stack React Native/Capacitor app with an AI layer.

It converses with owners about their pet's logged history (symptoms, meds, vitals) and answers natural-language questions against real structured data. It detects adherence and symptom patterns across logged history and surfaces them proactively, instead of the owner having to notice trends manually. It generates a structured, vet-ready PDF health report from scattered logged data in one tap. It runs a secure, encrypted medical-document vault per pet.

## Stack

React + TypeScript, Capacitor (iOS/Android), Supabase (Postgres + RLS), Claude/LLM integration for the AI assistant and pattern detection.
